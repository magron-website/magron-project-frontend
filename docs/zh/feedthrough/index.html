Feedthrough

基于 Magnetic Fluid Seal 的高可靠性真空 Feedthrough 解决方案

Feedthrough 是在向真空腔室或密闭设备内部传递旋转运动、线性运动、气体、电信号等的同时，保持内部环境真空度与洁净度的核心部件。

基于 Magnetic Fluid Seal 的 Feedthrough 通过在旋转轴周围形成的磁流体密封结构，阻断气体泄漏、外部污染物侵入及粉尘侵入。适用于半导体、显示、真空镀膜、离子注入、机器人传送、航空航天及研究设备等要求高可靠性与长寿命的设备。

Vacuum Sealing

稳定保持真空腔室内部的压力与洁净度。

Rotary Motion Transfer

通过旋转轴将外部动力传递至设备内部。

Low Particle Generation

采用磁流体密封结构减少颗粒产生。

Custom Specification

可根据轴径、转速、真空度条件进行规格评估。

真空馈通是什么部件？

馈通是在将旋转/直线运动、气体或电信号从真空腔体外传递至腔体内的同时，保持内部真空度与洁净度的核心部件。MAGRON 馈通以磁流体对旋转轴进行非接触密封，同时降低泄漏与颗粒产生。

有哪些结构型式？
提供小型旋转导入器、贯通式安装、法兰安装、重载型，以及中空轴卡匣式·法兰式·悬臂式。将三轴同轴主轴与 50mm 直线行程结合的复合驱动型，适用于 Cluster Tool、300mm 晶圆、LCD 大型基板处理及真空传送机器人。
是否可以定制？
可以。请告知轴径、转速、所需真空度、法兰规格及使用气体种类，我们将据此评估合适的规格方案。
是否提供泄漏性能数据？
氦气泄漏率低于 10⁻¹² Pa·m³/s（10⁻¹¹ Torr·ℓ/s），可达真空度约为 10⁻⁶ Pa（10⁻⁸ Torr），使用温度范围为 0~150℃。各型号的扭矩容量与轴承·壳体·轴材质可在本页规格表中查看。

Hollow Shaft — Flange Mount Type

中空轴·法兰安装式

Hollow Shaft — Cantilevered Seal Type

中空轴·悬臂密封式

用于单侧支撑结构或特殊安装条件的中空轴导入器。采用应对反应性气体的密封结构，适用于难以采用普通法兰型的设备。

  • Conflat flange is available as an option.

特殊用途导入器

Special Purpose

为应对超高真空、反应性气体、气体供给等特殊工艺条件而设计的导入器。

Ultra High Vacuum Feedthroughs

超高真空（UHV）导入器

  • MSCV-012WC
  • 10⁻⁷ Pa

用于在高真空·超高真空环境中传递旋转运动的产品。采用低蒸气压 UHV 用磁流体与差动排气结构，支持 10⁻⁷ Pa（10⁻⁹ Torr）级真空。

  • Ferrofluid for UHV operation, which has low vapor pressure at high temperature, is used.
  • The main chamber is protected from bake-out gas by differential pumping.
  • Baking condition is the same as for a TMP.
  • The differential pumping line and main pumping line can be unified up to a 10⁻⁹ Torr vacuum level.
  • The compact equipment can be provided with a simplified seal construction for UHV processing.

Purge Mode Type

吹扫模式式

  • MSFV-020WC
  • CVD / Furnace

在密封单元中采用吹扫气体结构，抑制工艺气体·污染物进入密封区域及沉积堆积。适用于反应性气体、CVD、炉等发生沉积的工艺。

  • Longer life is realized by installing a purge-gas structure in the seal unit.
  • This prevents process gas from flowing into the seal area and eliminates deposition near the seal.
  • Intended for reactive-gas, CVD and furnace applications that generate depositing material.

Rotary Gas Union

旋转气体接头

  • MSFH-100NH
  • Gas supply

通过旋转轴供给或排出高纯度气体的导入器。应用于需在保持旋转运动的同时连接气路的工艺设备。

  • Highly purified gas can be supplied into a chamber through this feedthrough.
  • A typical application is a rotary gas union for light-bulb manufacturing equipment.
