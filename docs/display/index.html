대형 자성유체 디스플레이

Large Ferrofluid Display

자성유체의 움직임을 대형 디스플레이 형태로 구현한 전시·홍보·체험용 콘텐츠입니다. 자기장에 반응하는 유체의 움직임을 영상으로 확인해보세요.

대형 자성유체 디스플레이는 무엇인가요?

자기장에 반응하는 자성유체의 움직임을 대형 화면 형태로 구현한 전시·홍보용 콘텐츠입니다. 관람객의 시선을 끄는 시각 효과가 강해 과학관과 전시관, 기업 홍보관, 미디어아트, 교육·체험 부스에 활용됩니다.

어디에 설치하나요?
과학관·전시관, 기업 홍보관, 미디어아트 전시, 교육·체험 부스 등에 설치합니다. 실제 작동 모습과 적용 사례는 이 페이지의 포트폴리오 영상에서 확인할 수 있습니다.
원하는 크기로 제작할 수 있나요?
가능합니다. 설치 공간, 희망 크기, 전시 기간, 운영 환경을 알려주시면 규격을 검토해 드립니다.
자성유체는 어떻게 움직이나요?
자성유체는 자기장에 반응해 자기력선을 따라 모이고 흩어집니다. 자기장의 세기와 순서를 제어해 유체의 움직임을 연출합니다.

대형 자성유체 디스플레이의 실제 작동 모습과 전시 적용 사례를 영상으로 확인할 수 있습니다.
